## defines a programming project’s required features, constraints, deliverables, and out-of-scope items.

The required features are three greedy strategies, a brute forced exhaustive search,
and a comparison output.

Highest Rating, Lightest First, and Best Rating to Weight. 
All possible subsets of about 12 items that have around 4096 possible subsets.
Results of all 3 greedy strategies,
Result of the brute-force optimal,
A brief printed summary identifying which strategies matched the optimal and which did not.

Some constraints are the weight limit and indivisibility. Maybe even only one code language is a constraint.
Hard cap of only 700 kg for the weight.
All 12 are indivisible no fractional parts.

The deliverables are the Github link, a report and a video where we all participate in them.

Some out-of-scope items would include fractional selections and multi-resource constraints.
Dividing the experiments like partial weights seems out of scope.
Factoring secondary stuff like power consumption, and bandwidth.
