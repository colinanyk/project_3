## 5 bullets on data structures, invariants, assumptions, and tradeoffs

1 Data Structure Representation
We are modeling the experiments as structured entities containing discrete attributes. 

2 Greedy Strategy Trade off
The algorithms we have execute with minimal memory overhead at the cost of global optimization.

3 Indivisibility Assumption
We have the experiments as discrete and indivisible.

4 Traceability
Docs folder as well as Github helps keep track of who does what.

5 Reproductive Ability
We are running this with Java and having doc comments keep track of what does what to be able to be read properly and normally.
